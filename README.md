# Blue Hills ERP

Hospitality ERP demo for **Blue Hills Camp** — front office, housekeeping, restaurant, procurement, and finance modules in a single React app.

## Stack

- React + TypeScript
- Vite
- Local persistence via `localStorage` (demo mode)

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Modules

- **Dashboard** — occupancy, front office today, housekeeping snapshot, live attention queue
- **Front Office** — reservations, check-in/out, enquiries, keys, guest messages
- **Housekeeping & Activities** — daily linen/chemical/amenity checklist, lodge room board, cleaning queue
- **Restaurant & Kitchen** — POS and kitchen display demo
- **Procurement & Stores** — purchase requests
- **Finance & Night Audit** — revenue, cash controls, reports

## Demo data

Use **Reset Demo** in the app to reload seed data. Housekeeping uses real lodge units: Zebra, Kudu, Impala, and Ladies Dormitory.

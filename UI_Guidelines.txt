# Blue Hills Camp Hospitality ERP
## User Interface & Experience Standards

Version: 1.0

---

# PURPOSE

This document defines the UI/UX standards for the Blue Hills Camp Hospitality ERP.

It ensures every screen follows a consistent visual language, interaction model and navigation pattern.

This document is intended for:

- Claude Code
- Cursor AI
- UI Designers
- Frontend Developers

Every screen generated must comply with these standards.

---

# DESIGN PHILOSOPHY

The system is Enterprise Software.

It is NOT a marketing website.

It is NOT a Bootstrap admin template.

It is NOT a CRUD application.

Users spend 8-10 hours every day using this software.

The interface must therefore prioritise:

• Speed

• Simplicity

• Clarity

• Information Density

• Consistency

• Professionalism

Think:

Oracle Opera PMS

Cloudbeds

Mews

Linear

Stripe Dashboard

Notion

Microsoft Dynamics

---

# DESIGN GOALS

Users should immediately know:

Where they are

What they are working on

What requires attention

What action comes next

The software should reduce thinking.

# USER EXPERIENCE PRINCIPLES

Reception staff should complete a reservation in under 2 minutes.

Restaurant staff should complete an order in under 30 seconds.

Housekeeping should update room status in under 10 seconds.

Managers should obtain any report within 3 clicks.

The system should minimise typing wherever possible.

---

# DESIGN RULES FOR CLAUDE CODE

When generating UI:

Never create generic admin dashboards.

Always think like enterprise software.

Prioritise usability over visual effects.

Use realistic hospitality data.

Maintain consistent spacing.

Reuse components.

Use shadcn/ui components wherever possible.

Prefer drawers over navigating away.

Keep important actions visible.

Every page must look presentation-ready.

If unsure, favour simplicity over decoration.
